# Weather App 🌦️

A responsive weather application built using HTML, CSS, and JavaScript that provides real-time weather information through API integration. Users can search for any city and instantly view current weather conditions, temperature, humidity, wind speed, and other weather details in an intuitive interface.

## 🚀 Features

* Real-Time Weather Data
* City-Based Weather Search
* Current Temperature Display
* Humidity Information
* Wind Speed Monitoring
* Dynamic Weather Icons
* Responsive User Interface
* API Integration
* Error Handling for Invalid Locations

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Weather API
* Fetch API
* Async/Await

## ▶️ Installation & Setup

1. Clone the repository

```bash
git clone https://github.com/your-username/Weather-App.git
```

2. Navigate to the project folder

```bash
cd Weather-App
```

3. Open the project in your preferred code editor.

4. Add your Weather API key in the JavaScript file if required.

5. Open `index.html` in your browser.
